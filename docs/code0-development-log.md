## Engineering Task Records

| Task ID | Date & Time | Engineering Task | Code0 Suggestion | Manual Review & Engineering Adjustment | Empirical Validation Evidence |
|:---:|:---:|:---|:---|:---|:---|
| **TASK-01** | Oct 9, 2026 16:15 IST | Architecture Topology & Directory Scaffolding | Proposed splitting the platform into multiple decoupled microservices (Auth Service, Catalog Service, Interest Service) communicating over HTTP/gRPC. | **Rejected microservices suggestion.** For an early-stage 72-hour delivery window, microservices introduce network latency, distributed transaction failure modes, and DevOps bloat without any scalability justification. Enforced a **Modular Monolith** in Express + TypeScript with domain-driven modules (`auth`, `startups`, `interests`, `bookmarks`, `dashboard`). | Local cold startup is instantaneous; zero Docker dependencies required; integration tests run against a single unified database instance in <12 seconds. |
| **TASK-02** | Oct 9, 2026 16:21 IST | Concurrency & Race-Safe Interest Pipeline | Proposed an application-layer check using `const existing = await Interest.findOne(...)` before creating a new interest record. | **Identified TOCTOU vulnerability.** Two concurrent requests arriving at the same millisecond bypass application-level checks. Replaced with a **MongoDB compound unique index** `{ startupId: 1, investorId: 1 }` and atomic conditional updates `findOneAndUpdate({ status: 'PENDING' })`. Explicitly caught error code `11000` to return HTTP `409 INTEREST_ALREADY_EXISTS`. | Automated concurrency test: two parallel HTTP POST interest requests for the same startup-investor pair fired with `Promise.all()` yield exactly one `201` and one `409`, with exactly 1 document in MongoDB. |
| **TASK-03** | Oct 9, 2026 19:21 IST | Express 5 Route Params Type Compatibility | Controller handlers initially failed TypeScript compilation (`error TS2345: Argument of type 'string \| string[]' is not assignable to parameter of type 'string'`). | Code0 suggested ignoring TypeScript errors via `@ts-ignore` comments. **Rejected suppression.** The root cause was Express 5's upgraded type definitions where `req.params.id` is typed as `string \| string[]`. Corrected controllers by explicitly narrowing and asserting `const id = req.params.id as string;`. | `tsc --noEmit` exited cleanly with exit code `0` across all controllers without any `@ts-ignore` escapes. |
| **TASK-04** | Oct 9, 2026 19:31 IST | Vite Client Environment & SEO Integration | Code0 generated an API client using `import.meta.env.VITE_API_BASE_URL` without ambient Vite client type definitions, causing `Property 'env' does not exist on type 'ImportMeta'`. | Created `client/src/vite-env.d.ts` with `/// <reference types="vite/client" />` and explicit `ImportMetaEnv` typing. Added Inter font via Google Fonts, WCAG accessible focus rings, and proper HTML5 meta description tags. | Client production build `tsc && vite build` completed in 13.97s with zero type errors and zero bundle failures. |
| **TASK-05** | Oct 9, 2026 19:23 IST | Automated Integration Test Suite & Concurrency | Code0 proposed basic happy-path unit tests with mocked Mongoose models. | **Refactored to comprehensive integration tests.** Mocking models masks database index bugs and race conditions.
